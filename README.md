# RAUF BAHERUNI 360 Panorama Studio

Free browser-only GitHub Pages project. Put `index.html` and `rauf-baheruni.jpg` in the same repository.

Features: branded interface, photo picker, 2:1 panorama render, RAUF BAHERUNI watermark, JPG download, drag preview, and experimental Instagram spin-video export.

A single 2D photo cannot reveal the unseen rear scene. Instagram interactive 360-photo support is not guaranteed; the spin-video is provided as a practical fallback.
